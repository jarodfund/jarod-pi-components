# 学术派 · 智能体资源

[简体中文](README.md) · [English](README.en.md) · [学术派产品仓库](https://github.com/jarodfund/jarod-pi)

这里存放 **学术派 / Jarod-Pi** 的版本化智能体资源目录、来源记录和发布说明。资源包放在 GitHub Releases，不放入 Git 源码历史。

## 用户怎么使用

在学术派中选择智能体即可。缺少的依赖由客户端按需下载，共享依赖只需安装一次；不必手动下载所有资源，也不必逐个克隆上游项目。

这是资源仓库，不是客户端安装包。Windows、Linux 和 macOS 的程序入口在[产品仓库](https://github.com/jarodfund/jarod-pi)。目前首次 GitHub 资源发布仍在准备，不能把本页视为已上线声明。

## 三层结构

| 层级 | 内容 | 用途 |
| :--- | :--- | :--- |
| 上游源码 fork | 原作者的代码、技能与许可 | 追踪来源和维护适配 |
| 本资源仓库 | 适配资源、固定版本、签名目录 | 供客户端安装经过验证的组合 |
| 产品仓库 | 桌面程序与客户端压缩包 | 用户下载和日常使用 |

Fork 不等于适配资源。直接下载上游最新分支的 ZIP，不能替代学术派固定版本的资源包。

## 下载与校验

客户端按平台获取 `portable-windows-x64.json`、`portable-linux-x64.json`、`portable-macos-arm64.json` 或 `portable-macos-x64.json`。

- 目录使用 Ed25519 签名，客户端内置公钥；私钥不公开。
- 每个 ZIP 按 SHA-256 命名，大小与摘要由签名目录约束。
- 目录内规范路径为 `packages/<sha256>.zip`；GitHub Release 对应平铺资产 `<sha256>.zip`，客户端负责映射。
- 客户端支持断点续传，解压前检查摘要，拒绝危险路径和不完整资源。
- 国内镜像尚未配置。不假定某个 IP 地区一定有更快的下载速度，不把未经审查的公共代理作为默认下载源。

资源目录包含各系统的能力边界；Linux/macOS 尚有部分原生依赖等待构建和实机验证，不能将 Windows 资源直接用于其他平台。
